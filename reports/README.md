# Report evidence

This directory contains reproducible outputs generated by the pipeline and modelling scripts. The local working copy may contain more outputs than are committed to GitHub.

## Repository-safe evidence

The following kinds of outputs may be committed when they contain only aggregate or privacy-safe information:

- Great Expectations validation summaries;
- cleaning aggregate summaries;
- temporal-representativeness and feature-selection summary tables;
- model-comparison and calibration summaries;
- representation/bias aggregate summaries;
- presentation-ready figures that do not expose individual records;
- privacy-audit evidence after confirming that it contains no raw identifier values or row-level personal data.

For Module 3 submission evidence, the most useful outputs include:

- `tables/gx_raw_validation.json`
- `tables/gx_interim_validation.json`
- `tables/gx_processed_validation.json`
- `tables/cleaning_summary.json`
- `tables/model_dataset_summary.json`
- `tables/representation_bias_summary.json`
- selected temporal, feature-selection, and model-comparison summaries used in the presentation
- selected figures used to explain the pipeline or modelling decisions

## Local-only outputs

Do not commit:

- raw, interim, or processed row-level customer datasets;
- extracts containing `msisdn` or another direct identifier;
- ad hoc row-level debugging exports;
- screenshots or logs that expose local secrets, credentials, or unnecessary personal data.

The pipeline privacy audit log is generated under `reports/privacy/`. It is designed to be privacy-safe, but it should still be reviewed before being added to a submission or repository snapshot.

## Reproducibility

Generated outputs are evidence, not the source of truth for transformation logic. The authoritative implementation remains the code under `src/`, while governance interpretation and limitations are documented under `docs/governance/`.
